# 08. Nozzle (배기 노즐 및 추력 계산)

**역할:** 터빈 출구 유동을 받아 배기 질량유량, 배기속도, 추력을 계산. 아음속(subsonic) 배압조건과 초킹(choked) 조건을 분기 처리하는 준1차원 등엔트로피 노즐 모델.

---

## 모델 개요

| 항목 | 내용 |
|------|------|
| 모델링 언어 | VHDL-AMS |
| 입력 | pressure_in, t_in |
| 출력 | air_vel, mdot_nozzle, thrust |
| 연결 | Turbine(cfluid_b) -> Nozzle |

## 핵심 파라미터 (근거: GitHub Issue #31, 2026-07-29 컴포넌트 코드 공유)

| 파라미터 | 기호 | 값 | 설명 |
|----------|----|----|------|
| 노즐 면적 | area | 0.3 m^2 | generic 기본값 |

## 지배 방정식 (요약)

```
p_cr = ((2/(gamma+1))^(gamma/(gamma-1))) * p_in   -- 임계압력

if p_back > p_cr:  -- 아음속(비초킹)
  p_e = p_back
  mdot, thrust, air_vel 계산 (등엔트로피 팽창)
else:               -- 초킹
  p_e = p_cr
  mdot = 초킹 질량유량식
  thrust = mdot * sqrt(2*cp*t_in*ratio_term) + area * (p_cr - p_e)
```

## ⚠️ 확인된 버그 (수정 미반영, 이번 PR 범위 밖)

저장소 최상위 README.md 4장 [항목5]에서 이미 "확정된 버그"로 기록된 사항을 이 문서에도 명시합니다.

- **위치**: 초킹(choked) 분기의 추력식
- **문제**: `p_e := p_cr`로 재정의한 직후 추력식에서 `(p_cr - p_e)` 항을 사용하고 있어, 이 항이 **항등적으로 0**이 됩니다. 즉 초킹 상태에서 발생해야 할 압력 추력항(pressure thrust term)이 실제로는 전혀 반영되지 않습니다.
- **근거**: Issue #31(2026-07-29) 공개 소스코드를 이 문서 작성 시점(2026-08-24)에 직접 재확인함. 코드 원문:
  ```
  p_e := p_cr;
  ...
  thrust_n := mdot * sqrt(2.0 * cp * t_in_safe * sqrt_arg2) + area * (p_cr - p_e);
  ```
- **영향 범위**: 초킹 조건(고출력/고고도 등 배압이 임계압 이하인 구간)에서 추력이 실제보다 과소평가됩니다.
- **처리 방침**: 이번 문서화 작업(컴포넌트 문서 동기화 PR)에서는 코드를 임의로 수정하지 않습니다. 별도 수정 이슈로 등록합니다.

## 추가 미해결 항목

- **면적 비현실성**: 저장소 최상위 README.md 4장 [항목6]에 따르면 area=0.3 m^2는 질량연속성 기준 역산값(약 0.0096 m^2)과 약 31배 차이가 납니다. 실제 스키매틱 인스턴스에서 override된 값인지 미확인 상태입니다.
